Controls:

Triggers/ RAnalog: Paddle Control 
DPAD/LAnalog Left: Move Tetromino Left
DPAD/LAnalog Right: Move Tetromino Right
DPAD/LAnalog Down: Speed Tetromino Decent
DPAD UP/ B Button: Tetromino Rotate
A Button: Tetromino Fast Drop
R Analog Click: Open Screen Adjust
Start Button: Pause Game
Back Button: Exit Game
